## Publishing on GitHub Pages

1. Create a repository named **`bdibm313`** under the `drhaas-eubs` account.
2. Upload the contents of this folder to the repository root (the files must sit at the top level, including `.nojekyll`).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
6. After a minute the site is live at `https://drhaas-eubs.github.io/bdibm313/`

All internal links are relative. No build step, no external dependencies — plain HTML, CSS and a little vanilla JS.
